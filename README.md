##  Project Overview

This project is part of the Digital Literacy course at VIT Bhopal. The objective is to build a Digital Literacy Portfolio as a Student Digital Ambassador. It focuses on developing essential digital skills such as creating professional profiles, using online collaboration tools, maintaining proper communication, and understanding cyber safety.

The project is divided into five tasks, each targeting a different aspect of digital literacy.
